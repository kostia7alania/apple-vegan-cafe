# MVP-123 execution ledger

Это не список работ ради числа 123 и не замена реализации. Каждая строка должна
закончиться наблюдаемым результатом для гостя или владельца кафе.

Текущий срез: **123 outcomes = 66 DONE · 0 READY · 57 BLOCKED**.

- `DONE` — есть прямое доказательство в текущем репозитории или рабочем diff.
- `READY` — можно делать автономно, не выдумывая business facts.
- `BLOCKED` — нужен ответ/ассет/доступ владельца или данные после запуска.
- DONE из незакоммиченного diff означает «реализовано в текущей смене», а не
  «уже задеплоено»; финальная интеграция остаётся общей задачей смены.

## Следующий loop

Начинать не с попытки «закрыть больше строк», а с верхнего READY, которое не
требует новых фактов. Когда владелец вернёт facts lock, связанные BLOCKED строки
разблокируются пакетом: pin → directions/geo/GBP, messaging → CTA, payment и
visit facts → contact/FAQ, photo permission → real visual trust.

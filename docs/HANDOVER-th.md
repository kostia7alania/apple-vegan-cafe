# คู่มือดูแลเว็บไซต์ร้าน (สำหรับครอบครัว ใช้จากมือถือได้เลยค่ะ)

ทุกอย่างในคู่มือนี้ทำจากโทรศัพท์ได้ค่ะ เข้าไปที่ **https://apple-vegan-cafe.com/admin**
เมนูและช่องต่างๆ ในระบบเป็นภาษาไทยแล้วค่ะ (มีภาษาอังกฤษกำกับในวงเล็บ) เหลือปุ่มของระบบไม่กี่ปุ่มที่เป็นภาษาอังกฤษ เช่น **"Save"** = บันทึก — คู่มือนี้บอกทุกปุ่มที่ต้องกดทีละขั้น
สิ่งสำคัญที่สุดที่ต้องจำ: แก้อะไรเสร็จให้กดปุ่ม **"Save"** แล้วรอประมาณ **3 นาที** การเปลี่ยนแปลงจะขึ้นเว็บจริงเองค่ะ

## 1. การเข้าสู่ระบบครั้งแรก

บัญชีที่ใช้เข้าเว็บคือบัญชี **GitHub** ค่ะ ครั้งแรกสุดจะมี**อีเมลคำเชิญจาก GitHub** ส่งมาที่อีเมลของเรา

**ครั้งแรกสุด — รับคำเชิญ (ทำครั้งเดียวค่ะ):**

1. เปิดอีเมลคำเชิญจาก GitHub (หัวข้อประมาณ "…invited you to collaborate") แล้วแตะปุ่ม **"Accept invitation"**
2. ถ้ายังไม่มีบัญชี ให้เลือกสมัครสมาชิก แล้วแตะ **"Continue with Google"** — ใช้บัญชี Google ของเราได้เลย ไม่ต้องจำรหัสผ่านใหม่ค่ะ
3. ตอนตั้งชื่อผู้ใช้ (username) แนะนำชื่อกลางๆ เช่น `applevegancafe-owner` ค่ะ
4. เสร็จแล้วแตะ **"Accept invitation"** อีกครั้ง เป็นอันเรียบร้อยค่ะ

**การเข้าใช้งานทุกครั้ง:**

1. เปิด Safari (iPhone) หรือ Chrome (Android) แล้วพิมพ์ `apple-vegan-cafe.com/admin`
2. แตะปุ่ม **"Sign In with GitHub"**
3. ถ้า GitHub ถามให้เข้าสู่ระบบ เลือก **"Continue with Google"** (บัญชีเดิมที่สมัครไว้ค่ะ)
4. ถ้ามีหน้าจอถามสิทธิ์ ให้แตะปุ่มสีเขียว **"Authorize"** (ถามแค่ครั้งแรกครั้งเดียวค่ะ)
5. เข้าสำเร็จแล้วจะเห็นเมนูรายการ เช่น **"รายการอาหาร (Menu dishes)"**, **"บล็อก — ไทย (Blog TH)"**, **"ตั้งค่าเว็บไซต์ (Site settings)"**

**ทำให้เปิดง่ายเหมือนแอป (แนะนำมากค่ะ):**

- iPhone: ในหน้า /admin แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → เลื่อนหา **"Add to Home Screen"** → **"Add"**
- Android: แตะจุดสามจุดมุมขวาบน → **"Add to Home screen"** → **"Add"**
- ต่อไปแค่แตะไอคอนบนหน้าจอโฮมก็เข้าได้เลย ไม่ต้องพิมพ์อะไรอีกค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: หน้าเข้าสู่ระบบที่มีปุ่ม "Sign In with GitHub" และเมนูรายการหลังเข้าสำเร็จ]

## 2. เปลี่ยนราคาอาหาร

เมนูบนเว็บมี 5 หมวด ตรงกับใน Grab ค่ะ ช่อง **"หมวดหมู่ (Category)"** ของแต่ละจานเลือกเป็นภาษาไทยได้เลย:
อาหารจานเดียว · กับข้าว · ของทานเล่น · ฟาสต์ฟู้ด · เครื่องดื่ม

1. แตะ **"รายการอาหาร (Menu dishes)"** — จะเห็นรายการอาหารทั้งหมด พร้อมราคา (฿) ต่อท้ายชื่อ
2. หาจานที่ต้องการ (พิมพ์ชื่อในช่องค้นหาด้านบนได้ค่ะ) แล้วแตะเข้าไป
3. เลื่อนหาช่อง **"ราคา บาท (Price, THB)"** ลบราคาเดิม แล้วพิมพ์ราคาใหม่เป็นตัวเลขอย่างเดียว เช่น `159` (ไม่ต้องใส่ ฿ หรือคำว่าบาทนะคะ)
4. อย่ากรอก **"ครอบครัวตรวจชื่อและคำอธิบายแล้วเมื่อ (Owner review date)"** เพียงเพราะแก้ราคา ช่องนี้ใช้เมื่อเจ้าของร้านตรวจชื่อและคำอธิบายของจานนั้นครบแล้วเท่านั้น ราคาใหม่บันทึกได้โดยไม่ต้องกรอกช่องนี้ค่ะ
5. ถ้าเจ้าของร้านตรวจชื่อและคำอธิบายครบ English/ไทย/Русский แล้ว จึงเลือกวันที่ตรวจจริงในช่องนั้น คำอธิบายจะเริ่มแสดงบนเว็บหลังบันทึก แต่ข้อมูลความเผ็ด/สารก่อภูมิแพ้ยังต้องใช้ช่องผู้ตรวจและวันที่ใน **"ข้อมูลอาหารที่ตรวจแล้ว (Verified food facts)"** แยกต่างหาก
6. แตะปุ่ม **"Save"** ด้านบน
7. รอ 3 นาที แล้วเปิดหน้าเว็บร้านดูราคาใหม่ได้เลยค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: หน้าแก้ไขจานอาหาร ชี้ตำแหน่งช่อง "ราคา บาท (Price, THB)" และปุ่ม "Save"]

## 3. ซ่อนเมนูที่หมด (สต๊อปลิสต์) — และวิธีเอากลับมา

ของหมดวันนี้? ไม่ต้องลบเมนูนะคะ แค่ปิดการแสดงชั่วคราวพอค่ะ

1. แตะ **"รายการอาหาร (Menu dishes)"** แล้วแตะจานที่หมด
2. หาสวิตช์ **"ยังขายอยู่ (Available)"** แล้ว**ปิดสวิตช์** (แตะให้ดับลง)
3. แตะ **"Save"** — อีก 3 นาทีจานนี้จะหายไปจากเมนูบนเว็บค่ะ

**พอของกลับมามีแล้ว:** เข้าจานเดิม **เปิดสวิตช์กลับ**ที่ **"ยังขายอยู่ (Available)"** แล้วแตะ **"Save"** — จานจะกลับมาโชว์เหมือนเดิมค่ะ

เกร็ดเล็กๆ: สวิตช์ **"โชว์หน้าแรก (Show on home page)"** คือการเลือกให้จานนั้นโชว์เด่นบนหน้าแรกของเว็บค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: สวิตช์ "ยังขายอยู่ (Available)" ตอนเปิดอยู่ และตอนปิด]

### 3.1 ตรวจข้อมูลความเผ็ด สารก่อภูมิแพ้ กลูเตน และ Jain ทีละจาน

เปิดสูตรหรือข้อมูลวัตถุดิบจริง แล้วตรวจ**ทีละจาน**ใน **"Menu dishes"** ห้ามเลือกหลายจาน
หรือเดาจากชื่อ หมวดหมู่ รูปถ่าย หรือจานที่ดูคล้ายกันค่ะ

1. **"Spicy level"** — เว้นว่าง (`null`) ถ้ายังไม่ตรวจ; `0` หมายถึงตรวจแล้วว่า
   ปกติเสิร์ฟไม่เผ็ด; `1`–`3` คือระดับเผ็ดปกติที่ตรวจแล้ว
2. **"Allergens status"** — เลือก `unknown` ถ้ายังตรวจสูตรไม่ครบ เลือก `verified`
   หลังตรวจแล้วเท่านั้น แล้วเลือกสารที่มีจริงใน **"Contains allergens"**
   `verified` พร้อมรายการว่างหมายถึงไม่พบสารในรายการที่ระบบตรวจเท่านั้น
   **ไม่ได้แปลว่า allergen-free** และไม่รับประกันเรื่อง cross-contact ค่ะ
3. **"No gluten ingredients"** — เลือก `unknown`, `yes` หรือ `no`; ใช้ `yes`
   เฉพาะเมื่อเช็กวัตถุดิบแล้วว่าไม่มีส่วนผสมที่มีกลูเตน ไม่ใช่คำรับรอง gluten-free
4. **"Jain friendly"** — เลือก `unknown`, `yes` หรือ `no` ตามสูตรและวิธีทำจริงเท่านั้น
5. เมื่อยืนยันค่าใดแล้ว กรอก **"Verified by"** เป็นชื่อผู้ตรวจ และ
   **"Verified at"** เป็นวันที่ `YYYY-MM-DD` จากนั้นตรวจอีกครั้งแล้วแตะ **"Save"**

ถ้ายังตอบค่าใดไม่ได้ ให้เก็บค่านั้นเป็น `unknown`/`null` ไว้ก่อน ปลอดภัยกว่าการเดาค่ะ

## 4. เพิ่ม/เปลี่ยนรูปอาหารที่อนุมัติสิทธิ์แล้ว

รูปอาหารจากแค็ตตาล็อก Grab ปัจจุบันซิงก์เข้าเว็บไซต์อัตโนมัติตาม Grab ItemID แล้ว
ไม่ต้องดาวน์โหลดจากแอปหรือเพิ่มซ้ำใน CMS ค่ะ ขั้นตอนด้านล่างใช้เฉพาะเมื่อร้านต้องการเพิ่ม
รูปต้นฉบับอื่นของตัวเองหรือรูปที่ได้รับอนุญาตอย่างชัดเจน

สำคัญมาก: รูปที่อัปโหลดจะอยู่ในพื้นที่สาธารณะของเว็บไซต์ จึงอัปโหลดได้เฉพาะรูปที่
ยืนยันสิทธิ์ครบแล้วเท่านั้น ถ้าสิทธิ์ยังเป็น **pending / unknown / denied**
ห้ามกด Upload และห้ามบันทึกรูปนั้นใน CMS ค่ะ

ห้ามแคปหน้าจอ คัดลอก หรือดาวน์โหลดรูปจาก **Google, HappyCow, Instagram**
หรือเว็บของคนอื่นมาเพิ่มเอง เพียงเพราะมองเห็นรูปออนไลน์ไม่ได้แปลว่าเรามีสิทธิ์

1. แตะ **"รายการอาหาร (Menu dishes)"** แล้วแตะจานที่ต้องการ
2. เลื่อนหาหัวข้อ **"รูปที่อนุมัติสิทธิ์แล้ว (Approved photos)"** แล้วแตะเพิ่มรายการใหม่
3. ใส่รูปใน **"รูปหลัก (Fallback image)"** หลังจากยืนยันสิทธิ์แล้วเท่านั้น ช่อง
   **"รูป responsive เพิ่มเติม (Optional variant)"** และ **"รูปขนาดใหญ่สุด (Largest variant)"**
   เว้นว่างได้ ถ้าเพิ่ม variant ให้กรอกความกว้างจริงของแต่ละไฟล์ด้วย
4. กรอกขนาดจริงของรูปหลักใน **"ความกว้างจริง (px)"** และ **"ความสูงจริง (px)"**
5. กรอกข้อมูลสิทธิ์ให้ครบ:
   - **"ที่มาของรูป (Origin)"** — `owner-original` ถ้าเจ้าของสิทธิ์ส่งต้นฉบับให้ร้าน หรือ `licensed` ถ้าใช้ตามใบอนุญาต
   - **"เจ้าของสิทธิ์ (Rights holder)"** — ชื่อเจ้าของสิทธิ์ของรูป
   - **"อนุญาตให้เผยแพร่ (Publication permission)"** — ต้องเป็น `granted`
   - **"ขอบเขตการอนุญาต (Permission scope)"** — ต้องเป็น `website-and-derivatives`
   - **"ผู้ยืนยันสิทธิ์ (Confirmed by)"** และ **"วันที่ยืนยัน (YYYY-MM-DD)"** — ผู้ยืนยันและวันที่ยืนยันจริง
6. ตรวจดูทั้งภาพว่ามีคนที่จำหน้าได้หรือไม่ แล้วเลือก **"ตรวจบุคคลในภาพ (People review)"**:
   - `none-confirmed` ใช้ได้เฉพาะหลังจากดูภาพชัดเจนแล้วว่าไม่มีคนที่ระบุตัวตนได้ จากนั้นเลือก **"Consent from visible people"** เป็น `not-applicable`
   - `recognisable-present` ใช้เมื่อมีคนที่จำได้ และเผยแพร่ได้ต่อเมื่อทุกคนอนุญาตแล้ว จากนั้นต้องเลือก **"Consent from visible people"** เป็น `granted`
   - ถ้ายังดูไม่แน่ใจว่ามีคนหรือไม่ ให้หยุดและอย่าอัปโหลดรูปค่ะ
7. ถ้า **"ที่มาของรูป (Origin)"** เป็น `licensed` ต้องกรอกข้อความเครดิตสาธารณะใน **"เครดิตสาธารณะ (Public credit)"** ตามเงื่อนไขเจ้าของสิทธิ์
8. ตรวจทุกช่องอีกครั้งแล้วแตะ **"Save"** หากอยากลบรูปเก่า ให้เปิดรายการรูปนั้นแล้วเลือก **"Remove"**

เคล็ดลับรูปสวย: ถ่ายตอนกลางวันใกล้หน้าต่าง ถือกล้องนิ่งๆ ให้เห็นจานเต็มๆ และพยายามไม่ให้ติดใบหน้าคนอื่นค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: หัวข้อ "รูปที่อนุมัติสิทธิ์แล้ว (Approved photos)" ช่องข้อมูลสิทธิ์ และตัวเลือก People review]

## 5. เปลี่ยนเวลาเปิด-ปิด และวันหยุดพิเศษ

1. แตะ **"ตั้งค่าเว็บไซต์ (Site settings)"** แล้วแตะ **"ที่อยู่และเวลาเปิด-ปิด (Address & opening hours)"**
2. ในหัวข้อ **"พัทยา (Pattaya)"** เลื่อนหา **"เวลาเปิด-ปิด (Opening hours)"** — แต่ละแถวมี:
   - **"วัน (Days)"** = เลือกวันได้เลย มีชื่อวันภาษาไทยให้เลือกค่ะ (จันทร์–อาทิตย์)
   - **"เปิด (HH:MM)"** = เวลาเปิด และ **"ปิด (HH:MM)"** = เวลาปิด — ใช้เวลาแบบ 24 ชั่วโมง เช่น `09:00` และ `20:30` ค่ะ
3. แก้เสร็จแตะ **"Save"**

**วันหยุดพิเศษ / เทศกาล:** ในหน้าเดียวกัน เลื่อนหา **"วันพิเศษ/วันหยุด (Special days)"**

1. แตะปุ่มเพิ่มรายการใหม่
2. **"วันที่ (YYYY-MM-DD)"** = ใส่วันที่แบบ ปี-เดือน-วัน เช่นวันสิ้นปี ใส่ `2026-12-31`
3. ถ้า**ปิดทั้งวัน** ให้เว้นช่อง **"เปิด (Opens)"** ว่างไว้เลยค่ะ / ถ้าเปิดสั้นลง ใส่เวลาเปิด-ปิดของวันนั้น
4. **"หมายเหตุ (Note)"** = ข้อความบอกลูกค้า เช่น `หยุดวันสงกรานต์`
5. แตะ **"Save"** — เว็บจะแจ้งลูกค้าให้เองค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: หน้า "ที่อยู่และเวลาเปิด-ปิด" ส่วน "เวลาเปิด-ปิด" และ "วันพิเศษ/วันหยุด"]

### 5.1 ยืนยันนโยบายราคา อาหาร และการรับจองโต๊ะ

ไปที่ **"Site settings" → "Payment, pickup & reservations" → "Pattaya"** และกรอกเฉพาะข้อมูลที่เจ้าของร้านยืนยันแล้วเท่านั้นค่ะ

**นโยบายราคา — "Confirmed price policy (leave empty while unknown)":** ถ้ายังไม่ได้เทียบและยืนยันราคา ให้เว้นว่าง (`null`) ห้ามเลือกจากการคาดเดาหรือดูเพียงช่องทางเดียว เมื่อยืนยันแล้วให้เลือกค่าที่ตรงจริงเพียงค่าเดียว:

- `same_everywhere` = ราคาอาหารแต่ละรายการเท่ากันทุกช่องทาง
- `website_matches_counter` = ราคาในเว็บไซต์ตรงกับราคาหน้าร้าน (ช่องทางอื่นอาจต่างกัน)
- `website_matches_grab` = ราคาในเว็บไซต์ตรงกับ GrabFood (ราคาหน้าร้านอาจต่างกัน)
- `channels_differ` = ราคาแตกต่างกันตามช่องทาง โดยไม่สรุปเองว่าช่องทางไหนถูกกว่า

**คำถามเรื่องส่วนผสม — "Confirmed channel for ingredient questions (leave empty while unknown)":** เว้นว่าง (`null`) จนกว่าจะยืนยันว่าทีมตอบคำถามเรื่องส่วนผสมผ่านช่องทางนั้นจริง แล้วจึงเลือก `phone`, `line` หรือ `whatsapp`; ช่องทางนี้ไม่ได้รับรองว่าอาหาร allergen-free และไม่ได้สัญญาว่าร้านจะปรับสูตรตามคำขอค่ะ

**การขอระดับความเผ็ด — "Spice requests (leave empty while unknown)":** เว้นว่าง (`null`) ถ้ายังไม่ได้ยืนยันกับครัว ห้ามเดาจากช่อง **"Base spicy level"** ของเมนู เพราะระดับความเผ็ดปกติไม่ได้แปลว่าปรับได้ค่ะ

- `not-offered` = ครัวยืนยันว่าเสิร์ฟตามสูตรมาตรฐานและไม่มีนโยบายปรับระดับความเผ็ดเป็นการทั่วไป; เว้น **"Confirmed request levels"** และ **"Exact dish scope / limitations"** ว่าง
- `offered` = เลือกเฉพาะระดับที่ครัวยืนยันจริง (`not-spicy`, `mild`, `medium`, `hot`) อย่างน้อย 1 ค่า และกรอก **"Exact dish scope / limitations"** ครบ English/ไทย/Русский ว่าใช้กับเมนูใดหรือมีข้อจำกัดอะไร
- ทั้งสองสถานะต้องกรอก **"Policy verified by"** และวันที่ **"Policy verification date"**; เว็บไซต์จะแสดงข้อมูลนี้บนหน้าเมนูและ FAQ เฉพาะเมื่อบันทึกครบและถูกต้องเท่านั้นค่ะ

**ข้อมูลสำหรับผู้ที่ต้องการอาหารฮาลาล — "Halal guidance (leave empty while unknown)":** ถ้ายังไม่ได้ยืนยันทั้งเรื่องใบรับรองและแอลกอฮอล์ที่ใช้ในการปรุงอาหาร ให้เว้นทั้งส่วนเป็น `null` เว็บไซต์จะบอกเพียงว่าเมนูเป็นอาหารจากพืช 100% และข้อมูลสองข้อนี้ยังไม่ยืนยัน โดยจะไม่กล่าวอ้างว่าอาหารเป็นฮาลาลค่ะ

- **"Halal certification status"** เลือก `not-certified` เฉพาะเมื่อร้านยืนยันว่าไม่มีใบรับรอง หรือเลือก `certified` เมื่อมีข้อมูลใบรับรองจริง
- ถ้าเลือก `certified` ต้องกรอก **"Certificate issuer / scope / reference"** ครบ English/ไทย/Русский เพื่อระบุผู้ออกใบรับรอง ขอบเขต หรือเลขอ้างอิง ห้ามใช้คำกว้าง ๆ ว่า “halal safe”; ถ้าเลือก `not-certified` ให้เว้นช่องรายละเอียดนี้ว่าง
- **"Cooking alcohol"** เลือก `used` หรือ `not-used` ตามวิธีทำจริงเท่านั้น
- กรอก **"Exact owner-approved context"** ครบ 3 ภาษา รวมทั้ง **"Guidance verified by"** และวันที่ `YYYY-MM-DD` ให้ครบในครั้งเดียว ถ้าขาดช่องใดระบบจะไม่เผยแพร่ข้อมูลชุดนี้ค่ะ

**รับอาหารที่ร้าน — "Pickup (leave empty while unknown)":**

- ถ้ายังไม่ยืนยันว่าเปิดรับ pickup หรือไม่ ให้เว้นทั้งส่วนเป็น `null`; เว็บไซต์จะไม่แสดงคำกล่าวอ้างเรื่อง pickup
- ถ้าร้านยืนยันว่า **ไม่รับ pickup** ให้ปิด **"Pickup available"** และเว้นช่องทางสั่ง เวลาล่วงหน้า และหมายเหตุราคาให้ว่างทั้งหมด
- ถ้าร้านยืนยันว่า **รับ pickup** ให้เปิด **"Pickup available"** และต้องเลือกช่องทางที่ใช้งานได้จริง (`phone`, `line` หรือ `whatsapp`); ช่อง `LINE`/`WhatsApp` ต้องมี URL ที่ยืนยันแล้วใน Site settings ด้วย
- **"Lead time"** และ **"Pickup price note"** เป็นข้อมูลเสริม แต่ถ้ากรอกต้องครบ English/ไทย/Русский และตรงกับนโยบายจริง ห้ามคาดเดาจาก GrabFood

**การจองโต๊ะ — "Reservations (leave empty while unknown)":**

- `null` = ยังไม่ทราบนโยบาย ให้เว้นทั้งส่วนว่างและยังไม่แสดงข้อมูลจองบนเว็บ
- `not-accepted` = ร้านยืนยันว่าไม่รับจอง; เว้น **"Request through"**, **"Minimum party size"** และ **"Lead time"** ว่าง ส่วน **"Optional reservation note"** ใส่ได้เฉพาะข้อความที่ยืนยันแล้ว
- `accepted` = รับคำขอจอง; ต้องเลือก **"Request through"** (`phone`, `line` หรือ `whatsapp`) และกรอก **"Lead time"** ครบ English/ไทย/Русский; เว้น **"Minimum party size"** ว่าง
- `large-groups-only` = รับคำขอเฉพาะกลุ่มใหญ่; ต้องเลือกช่องทางติดต่อ กรอกเวลาล่วงหน้าครบ 3 ภาษา และกรอก **"Minimum party size"** เป็นจำนวนตั้งแต่ 2 ขึ้นไป

เลือกช่องทางติดต่อเฉพาะช่องทางที่ร้านเปิดใช้งานและมีคนตอบจริงค่ะ **"Optional reservation note"** เป็นตัวเลือก แต่ถ้ากรอกต้องเป็นข้อมูลที่ยืนยันแล้วและครบ 3 ภาษา กด **"Save"** แล้วรอประมาณ 3 นาที

### 5.2 เพิ่มหรือลบช่องทางเดลิเวอรี

ไปที่ **"Site settings" → "Cafe info (name, phone, links)" → "Confirmed delivery links"** และใส่เฉพาะแพลตฟอร์มที่เจ้าของยืนยันว่าเปิดใช้งานจริงค่ะ

1. เลือก **GrabFood** หรือ **LINE MAN** ในช่อง **"Provider"** — ห้ามเพิ่มชื่ออื่นและห้ามเพิ่มแพลตฟอร์มเดิมซ้ำ
2. ใส่ **"Official share/order URL"** เป็นลิงก์ HTTPS ทางการของร้าน ห้ามเดา pin, URL หรือคัดลอกลิงก์ร้านอื่น
3. LINE MAN ใช้ได้เฉพาะ share/order link ทางการบน `lineman.line.me`, `lineman.onelink.me` หรือหน้า order ของ `wongnai.com`; เปิดลิงก์จากโทรศัพท์และตรวจว่าพาไปยังร้านที่ถูกต้องก่อนบันทึก
4. ถ้ายังไม่ยืนยันว่าแพลตฟอร์มเปิดรับออเดอร์อยู่ ให้ลบรายการนั้นหรือเว้นไว้ ไม่ควรเก็บ URL เปล่า
5. กด **"Save"** แล้วรอ deploy ประมาณ 3 นาที เว็บไซต์จะแสดงทุกลิงก์ที่ยืนยันแล้ว; ถ้ามีสองแพลตฟอร์ม ปุ่ม Order บนมือถือจะพาไปเลือกช่องทางในหน้า Menu

ตอนนี้ production ยังคงมีเฉพาะ GrabFood จนกว่าเจ้าของจะยืนยัน LINE MAN พร้อมลิงก์จริงค่ะ สถานะพื้นที่ ค่าจัดส่ง และเวลารับออเดอร์ให้ลูกค้าตรวจในแอปของแพลตฟอร์มนั้นเสมอ

> สำคัญ: ปุ่มจองบนเว็บเป็นเพียงการ **ส่งคำขอจอง** ไม่ใช่การยืนยันโต๊ะ ลูกค้าจะถือว่าจองสำเร็จได้เมื่อร้านตอบยืนยันเองเท่านั้นค่ะ

### 5.3 ตรวจแบบฟอร์มยืนยันข้อมูลก่อนเผยแพร่

1. คัดลอกแบบฟอร์มจาก `docs/MVP-FACTS-LOCK.md` กรอกเท่าที่เจ้าของยืนยัน และใช้ `unknown` เมื่อยังไม่ทราบ
2. ส่งไฟล์ `.md` หรือ `.txt` ที่กรอกแล้วให้ผู้พัฒนา ผู้พัฒนารัน `pnpm intake:check -- ชื่อไฟล์`
3. แก้รายการใน **ERRORS** ก่อน ส่วน **BLOCKED** ต้องรอคำตอบหรือหลักฐานเพิ่ม ห้ามนำไปใส่ CMS แทนด้วยการเดา
4. **PUBLISHABLE MAPPINGS** เป็นเพียงรายการบอกตำแหน่งให้ผู้พัฒนาตรวจและคัดลอกเอง สคริปต์ไม่แก้เว็บไซต์และไม่เผยแพร่ข้อมูลอัตโนมัติค่ะ

## 6. เขียนบทความ (Blog ไทย)

1. แตะ **"บล็อก — ไทย (Blog TH)"** แล้วแตะปุ่มสร้างบทความใหม่ (**"Create"** / เครื่องหมาย +)
2. กรอกช่องต่างๆ ค่ะ:
   - **"หัวข้อ (Title)"** = ชื่อบทความ (ภาษาไทยได้เลย)
   - **"คำโปรยสั้น สำหรับ Google (meta)"** = คำโปรยสั้นๆ 1–2 ประโยค
   - **"ลิงก์ URL (slug)"** = ชื่อลิงก์ เป็นภาษาอังกฤษตัวเล็ก คั่นด้วยขีด เช่น `songkran-menu-2026`
   - **"รหัสเชื่อมคำแปล (Translation key)"** = ใส่ค่าเดียวกับลิงก์ URL ได้เลยค่ะ
   - **"วันที่เผยแพร่ (Published)"** = วันที่ลงบทความ
   - **"เนื้อหา (Text)"** = เนื้อหาบทความ พิมพ์ได้ยาวเท่าที่ต้องการ ใส่รูปได้ด้วยค่ะ
3. สวิตช์ **"ฉบับร่าง (Draft)"** สำคัญมากค่ะ: **เปิด "ฉบับร่าง" อยู่ = บทความยังไม่แสดงบนเว็บ** (เก็บเป็นฉบับร่าง เขียนต่อวันหลังได้)
4. เขียนเสร็จ พร้อมเผยแพร่แล้ว ให้**ปิดสวิตช์ "ฉบับร่าง"** แล้วแตะ **"Save"** — อีก 3 นาทีบทความขึ้นเว็บค่ะ

> 📸 [ภาพหน้าจอจะเพิ่มภายหลัง: หน้าเขียนบทความใหม่ ชี้ช่อง "หัวข้อ", "เนื้อหา" และสวิตช์ "ฉบับร่าง"]

## 7. สิ่งที่ไม่ควรแก้เอง (ให้ติดต่อผู้พัฒนาค่ะ)

ช่องเหล่านี้เกี่ยวกับลิงก์และระบบหลังบ้าน ถ้าแก้ผิด ลิงก์เก่าที่ลูกค้าเซฟไว้หรือที่ Google จำได้จะพังค่ะ:

- **"ลิงก์ URL (slug)"** ในเมนูอาหาร และของบทความที่เผยแพร่ไปแล้ว
- **"slug เก่า — สำหรับ redirect (Previous slugs)"**
- **"รหัสเชื่อมคำแปล (Translation key)"** ของบทความที่มีหลายภาษาแล้ว
- **"ที่มาของข้อมูล (Data source)"** ในเมนูอาหาร

อยากเปลี่ยนชื่อลิงก์หรือย้ายบทความ ไม่ต้องลองเองนะคะ ทักผู้พัฒนาได้เลย เดี๋ยวจัดการให้ค่ะ

## 8. เปิด-ปิดรับออเดอร์ Grab และแก้เวลาใน Google Maps

เว็บไซต์ของเราแสดง "เวลาหน้าร้าน" (7:00–22:00) เท่านั้นค่ะ ส่วนการรับออเดอร์กลางคืนหรือการพักรับออเดอร์ชั่วคราว
ทำในแอปของแต่ละที่โดยตรง:

**พักรับออเดอร์ Grab ชั่วคราว (เช่น อยากพักผ่อนคืนนี้):**

1. เปิดแอป **GrabMerchant**
2. ที่หน้าหลักร้าน มองหาปุ่มสถานะร้าน แล้วเลือก **"Pause new orders"** (พักรับออเดอร์)
3. เลือกระยะเวลา แล้วยืนยัน — พอครบเวลาระบบเปิดรับเองค่ะ (หรือกดเปิดเองก่อนก็ได้)
4. ลูกค้าจะเห็นสถานะจริงในแอป Grab เสมอ ไม่ต้องแก้อะไรบนเว็บไซต์นะคะ

**แก้เวลาเปิด-ปิดใน Google Maps:**

1. เปิดแอป **Google Maps** แล้วล็อกอินบัญชีที่เป็นเจ้าของร้าน
2. ค้นหาร้านเรา → แตะโปรไฟล์ร้าน → **"Edit profile"** → **"Hours"**
3. แก้เวลา หรือเพิ่ม **"Special hours"** สำหรับวันหยุดพิเศษ แล้วบันทึก

จำง่ายๆ ค่ะ: **เว็บไซต์ = แก้ใน /admin · Grab = แอป GrabMerchant · Google = แอป Google Maps**
ถ้าเวลาหน้าร้านเปลี่ยนถาวร (เช่น เปิด 8:00 แทน) ต้องแก้ทั้งสามที่ให้ตรงกันนะคะ
